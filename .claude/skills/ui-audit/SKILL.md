# Аудит вёрстки

Ловит четыре класса дефектов, которые на этом сайте уже случались и которые
не видит `npm run build`:

1. **Переполнение вьюпорта** — блок вылезает за экран. Классический случай:
   элемент с фиксированной шириной или отрицательным полем внутри колонки,
   которая на промежуточной ширине сужается. Проявляется НЕ на 1440 и НЕ на
   390, а между ними, поэтому проверять надо минимум четыре ширины.
2. **Разъезд секций** — блоки на одной странице стоят по разным левым краям.
   Обычно у нового блока просто нет общего отступа контейнера.
3. **Битые внутренние ссылки** — относительные пути, посчитанные от неверного
   уровня вложенности. `npm run verify` их не ловит: он обходит только
   легаси-маршруты.
4. **Дубли h1** и JS-исключения.

## Как запускать

```bash
cd /workspace/andrewine && npm run build          # сначала собрать
node .claude/skills/ui-audit/scripts/check-layout.mjs
```

Скрипт сам поднимает статику из `dist/` и гасит её после себя.

Флаги: `--widths=1440,1024,768,390` (по умолчанию так и есть),
`--routes=/articles/,/premium_alcohol/` — ограничить набор страниц.

## Обязательно к соблюдению

- **Блокируй внешние запросы.** Сеть в песочнице закрыта; без блокировки
  страница висит минутами на Tilda CDN. В скрипте это уже сделано через
  `context.route(...abort())` — если пишешь свою проверку, повтори.
- **Отказы внешних ресурсов — не баги.** Tilda CDN и Wikimedia недоступны,
  поэтому шапка, подвал и картинки статей локально выглядят сломанными. Это
  ожидаемо. Смотри только на содержимое `.article-main`, `.premium`,
  `.not-found`.
- **Chromium:** `executablePath: '/opt/pw-browsers/chromium'`,
  `playwright-core` уже установлен.

## Как читать результат

Скрипт печатает список проблем или `✓ ЧИСТО`. Каждая строка —
`маршрут@ширина: класс элемента`.

Если видишь переполнение только на средних ширинах (960–1199) — почти
наверняка виноват блок с отрицательным полем (`margin: … -56px …`). Правильное
решение: включать выпуск за края только там, где место гарантировано
(`@media(min-width:1200px)`), а не подгонять число.

Если разъехались левые края — у нового блока нет отступа контейнера. На
хабах и разделах это `padding-left:96px` (сбрасывается в
`@media(max-width:1199px)`), на пилларе — общая ширина
`min(1120px, calc(100% - 48px))`.

Внутренние отступы тёмных панелей (`.category-cta`, `.article-checklist`) —
это НЕ разъезд: у панели с фоном есть своё поле, по общей линии идут её
границы, а не текст внутри.
