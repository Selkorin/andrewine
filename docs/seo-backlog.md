# Бэклог улучшений SEO/ГЕО — очередь для автоматических прогонов

Этот файл — общая память между запусками. Плановые агенты (Routine
«Andrewine SEO») берут **одну верхнюю невыполненную задачу**, делают её
целиком, отмечают `[x]` с датой и коротким итогом, коммитят и пушат.

**Ветка:** `claude/articles-section-bugs-1vz3yp`. В `main` не пушить.

## Правила для любого прогона

1. Одна задача за прогон. Не начинать вторую, даже если осталось время.
2. Оригинальные Tilda-шапку и подвал не трогать — их целостность проверяет
   `npm run verify`.
3. Перед пушем обязательно: `npm run build` (включает `astro check` и
   `verify`) — 0 ошибок, и проверка внутренних ссылок (см. ниже).
4. Тон контента: без конкретных цен и сумм, без обещаний выкупа
   («мы купим»), без привязки к датам, без выдуманных фактов. Оценка всегда
   «предварительная, по фотографиям, итог после очного осмотра».
5. Картинки — только реальные файлы Wikimedia Commons с проверенной
   лицензией и автором. Существование проверять поиском по точному имени
   файла; прямой доступ к wikimedia из песочницы закрыт прокси.
6. Если задача оказалась невыполнимой — отметить `[!]` с причиной и перейти
   к следующей, а не выдумывать результат.

Проверка ссылок (после сборки):

```bash
cd dist && python3 -m http.server 4600 &
# затем обойти /articles/ и все подстраницы, собрать <a href> и убедиться,
# что каждому внутреннему пути соответствует dist/<path>/index.html
```

## Очередь

- [ ] **Даты публикации в Article JSON-LD.** Сейчас у статей нет
      `datePublished` / `dateModified` — Google показывает их в выдаче и
      использует для оценки свежести. Добавить поля в `Article` (src/data/types.ts),
      проставить реальные даты добавления каждой статьи из git-истории
      (`git log --diff-filter=A --format=%aI -1 -- <файл>`), выводить в
      разметке. Даты не выдумывать.
- [ ] **Уникальные title для категорий в хлебных крошках хаба.** Проверить,
      что `seoTitle` каждой категории не длиннее 60 знаков в выдаче Яндекса
      (он обрезает раньше Google), при необходимости сократить, сохранив
      ключ и «| Andrewine».
- [ ] **Alt-тексты изображений в карточках.** В сетках хаба и категорий
      карточкам передаётся `alt=""` (декоративно, при наличии текстовой
      ссылки рядом — корректно), но у обложек статей alt должен содержать
      ключевой запрос. Проверить все 33 `imageAlt`, довести до 60–125 знаков
      с ключом и без переспама.
- [ ] **Страница «О журнале» / редакционная политика.** E-E-A-T: у сайта об
      оценке ценностей должна быть страница с описанием, кто оценивает и по
      каким принципам. Создать `/articles/about/` по шаблону категории,
      добавить в sitemap и в навигацию хаба.
- [ ] **Перелинковка между статьями внутри раздела.** Сейчас блок «Другие
      материалы» показывает 3 статьи, приоритет — своя категория. Добавить в
      конец текста статьи 2–3 контекстные ссылки на смежные материалы своего
      раздела с осмысленными анкорами (не «читать тут»).
- [ ] **Расширение категорий до 6 статей.** Для разделов с самым высоким
      спросом (виски, коньяк, вино) добавить по 2 статьи под запросы,
      которых ещё нет в разделе. Перед написанием — 2–4 поисковых запроса,
      чтобы не дублировать существующие темы.
- [ ] **Скорость: локальные копии изображений.** `npm run fetch:images`
      скачивает обложки с Wikimedia в `public/assets/articles/` под SEO-именами
      и переписывает пути. Выполнить, когда у окружения будет доступ к сети,
      и закоммитить результат.
