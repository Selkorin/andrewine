# Бэклог улучшений SEO/ГЕО — очередь для автоматических прогонов

Этот файл — общая память между запусками. Плановые агенты (Routine
«Andrewine SEO») берут **одну верхнюю невыполненную задачу**, делают её
целиком, отмечают `[x]` с датой и коротким итогом, коммитят и пушат.

**Ветка:** `claude/articles-section-bugs-1vz3yp`. В `main` не пушить.

## Стратегия (по итогам конкурентного анализа)

Главный вывод: позиционирование сайта — «принимаем в коллекцию элитный
алкоголь», но до 30.07.2026 слово «элитный» не встречалось ни в одной из
33 статей, а страницы под головной запрос не было вовсе. У лидеров выдачи
(alcovikup.ru, sellmewine.ru, skupka-star.ru, lombard-perspectiva.ru,
700ml.ru) такая страница есть у пяти из шести, и заголовки их статей почти
всегда содержат «элитный» или «коллекция».

Три рычага, на которые работает очередь:

1. **Головной запрос** — страница `/premium_alcohol/` (сделано) и статьи,
   которые на неё ссылаются.
2. **Незакрытые коммерческие интенты** — выкуп коллекции целиком и оценка
   как отдельная услуга. У конкурентов это отдельные страницы; кластер
   «куда продать коллекцию» вообще возглавляет информационная статья, то
   есть занят слабо.
3. **Связывание журнала с коммерцией** — 33 статьи не передавали вес на
   `buy_*`. CTA в конце статей добавлен; дальше — контекстные ссылки
   коммерческими анкорами и обратные блоки с коммерческих страниц.

Чего сознательно НЕ делаем: не копируем заявления конкурентов о лицензиях,
ассоциациях и офисах; не публикуем чужие или выдуманные ценники; не
создаём гео-страницы городов, пока не закрыты пиллар, коллекция и оценка —
иначе получим тонкие дубли.

## Правила для любого прогона

1. Одна задача за прогон. Не начинать вторую, даже если осталось время.
2. Оригинальные Tilda-шапку и подвал не трогать — их целостность проверяет
   `npm run verify`.
3. Перед пушем обязательно: `npm run build` (включает `astro check` и
   `verify`) — 0 ошибок, и проверка внутренних ссылок (см. ниже).
4. Тон контента: без конкретных цен и сумм, без обещаний выкупа
   («мы купим»), без привязки к датам, без выдуманных фактов. Оценка всегда
   «предварительная, по фотографиям, итог после очного осмотра».
5. Картинки — только реальные файлы Wikimedia Commons с проверенной
   лицензией и автором. Существование проверять поиском по точному имени
   файла; прямой доступ к wikimedia из песочницы закрыт прокси.
6. Если задача оказалась невыполнимой — отметить `[!]` с причиной и перейти
   к следующей, а не выдумывать результат.

Проверка ссылок (после сборки):

```bash
cd dist && python3 -m http.server 4600 &
# затем обойти /articles/ и все подстраницы, собрать <a href> и убедиться,
# что каждому внутреннему пути соответствует dist/<path>/index.html
```

## Очередь

- [ ] **Шесть статей под кластер «элитный алкоголь».** Слово «элитный» не
      встречается ни в одной из 33 статей, тогда как у skupka-star.ru и
      alcovikup.ru оно почти в каждом заголовке. Каждая статья — по общему
      шаблону (3 секции × 2 абзаца 35–55 слов, 4 пункта чек-листа, 3 FAQ
      по 25–45 слов, гео, картинка Wikimedia с подтверждённой лицензией) и
      должна 1–3 раза естественно употребить «элитный алкоголь». Писать
      можно по одной за прогон, отмечая сделанные:
      - [ ] `kak-prodat-elitnyy-alkogol` (general) → ссылка на
            `/premium_alcohol/`. С чего начать, какие сведения собрать,
            порядок оценки и осмотра, типичные ошибки владельца.
      - [ ] `kuda-prodat-kollekciyu-alkogolya` (general) → `/buy_collection/`
            (или `/premium_alcohol/`, пока её нет). Честный разбор вариантов:
            аукцион, профильный скупщик, частный коллекционер, площадки
            объявлений — плюсы и минусы. Без принижения конкурентов.
      - [ ] `ocenka-alkogolya-po-foto` (general) → `/estimate/` (или пиллар).
            НЕ дублировать существующую `photo-appraisal`: там перечень
            кадров, здесь — что оценщик видит по фото и чего принципиально
            не видит, почему диапазон, а не точная цифра.
      - [ ] `investicii-v-elitnyy-alkogol` (general) → `/premium_alcohol/`.
            Осторожно: это не финансовый совет, никаких обещаний доходности
            и процентов. Ликвидность, риски, подделки, хранение, горизонт.
      - [ ] `kollekcionnyy-viski-marki` (whisky) → `/buy_whisky/`. Не
            дублировать 4 существующие статьи раздела.
      - [ ] `samye-dorogie-hennessy` (cognac) → `/buy_cognac/`. Не
            дублировать `hennessy-louis-xiii`: там декантер и комплект,
            здесь — различение линеек между собой.
- [ ] **Страница выкупа коллекции целиком** — `/buy_collection/`. Запросы:
      «куда продать коллекцию алкоголя», «выкуп винной коллекции», «продать
      винный погреб». Сделать по образцу `src/pages/premium_alcohol.astro`
      (тот же дизайн-язык и набор разметки). Содержание: чем работа с
      собранием отличается от единичной бутылки, порядок работы с описью,
      как готовить коллекцию к осмотру, ссылки на все 8 категорий. Добавить
      в sitemap, связать с пилларом и с хабом статей.
- [ ] **Страница оценки как отдельной услуги** — `/estimate/`. Запросы:
      «оценка элитного алкоголя», «оценка алкоголя по фото бесплатно». У
      конкурентов это отдельный интент со своей страницей, у нас не закрыт
      нигде. Содержание: какие ракурсы нужны, что оценщик видит по фото и
      чего не видит, почему диапазон, сроки, бесплатность. Разметка Service
      + FAQPage. В sitemap и в перелинковку.
- [ ] **Обратная перелинковка: журнал → коммерция на уровне раздела.** На
      каждой из 8 категорийных страниц журнала (`/articles/<cat>/`) уже есть
      CTA вниз страницы. Добавить видимую ссылку на парную `buy_*` ещё и в
      шапке раздела, и контекстную ссылку на `/premium_alcohol/` анкором
      «элитный алкоголь» в лид-абзаце хаба `/articles/`.
- [ ] **Контекстные ссылки внутри текста статей.** Сейчас связь статья →
      коммерция только через CTA-блок в конце. Добавить в тело каждой статьи
      1 контекстную ссылку на парную `buy_*` коммерческим анкором («продать
      виски», «выкуп коньяка»), а не «читать далее». Реализовать полем в
      данных статьи, а не ручной вставкой HTML в текст.
- [ ] **Даты публикации в Article JSON-LD.** У статей нет `datePublished` /
      `dateModified`. Добавить поля в `Article` (src/data/types.ts),
      проставить реальные даты добавления из git-истории
      (`git log --diff-filter=A --format=%aI -1 -- <файл>`), выводить в
      разметке. Даты не выдумывать.
- [ ] **Брендовые статьи под горячие запросы.** По анализу, в выдаче по
      «продать Macallan» и «продать Dom Perignon» половина позиций занята
      магазинами, которые интент продажи не закрывают. Написать: Macallan
      (раздел виски, ведёт на `/buy_whisky/`) и Dom Pérignon по винтажам
      (раздел шампанского, ведёт на `/buy_champagne/`). Проверить, что не
      дублируют существующие `macallan-value` и
      `champagne-cristal-dom-perignon` — брать другой угол.
- [ ] **Статьи под алкоголь СССР.** Кластер «сколько стоит коньяк СССР»
      сейчас занят медиа и общетематическими блогами, коммерческих сайтов
      там мало. Написать материал о том, как определяют период и завод у
      советских выпусков, со ссылками на `/buy_cognac/` и `/buy_portwine/`.
      Цены не указывать.
- [ ] **Alt-тексты обложек статей.** Довести все `imageAlt` до 60–125 знаков
      с ключевым запросом, без переспама.
- [ ] **Страница «О журнале» / редакционная политика.** E-E-A-T: указать,
      кто оценивает и по каким принципам. Только реальные факты о команде —
      ничего не выдумывать. `/articles/about/`, в sitemap и в навигацию.
- [ ] **Скорость: локальные копии изображений.** `npm run fetch:images`
      скачивает обложки с Wikimedia в `public/assets/articles/` под
      SEO-именами и переписывает пути. Выполнить, когда у окружения будет
      доступ к сети, и закоммитить результат.
